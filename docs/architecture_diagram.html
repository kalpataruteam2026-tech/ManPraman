⚡ Vercel Deployment (Next.js 14)
Frontend hosted on Vercel Edge Network with zero-config CI/CD. Built with Next.js 14 App Router, React 18, Tailwind CSS 3.4, and PWA offline capabilities. Uses Dexie.js for IndexedDB persistence across 7 relational stores.
🚀 Render / Railway (FastAPI Backend)
High-performance Python 3.12 ASGI engine hosted on Render / Railway. Serves asynchronous endpoints under /api/v1 with GZip compression, PBKDF2/JWT security, OpenPyXL batch spreadsheet streaming, and two-pass ReportLab 5.0 canvas generation.
☁️ Cloudinary Document Storage (MaaS)
Media-as-a-Service (MaaS) pipeline for storing and fetching multi-sheet Excel workbooks, calibration certificates, on-pan physical verification stamp photos, and official 64-page OIML R 76-2 certified PDF/DOCX dossiers.
🛡️ AWS Cloud Infrastructure
High-availability cloud environment utilizing AWS VPC, EC2/ECS/App Runner microservices, AWS KMS/Secrets Manager for cryptographic key rotation, and CloudWatch telemetry for regulatory audit monitoring.
🤖 Dual ML & NLP Model Suites
Suite 1: Gradient Boosting Regressor (MPE surface), Random Forest (compliance probability), Isolation Forest (sensor anomaly detection), and TF-IDF search over 88 Legal Metrology gazette PDFs.
Suite 2: Multi-Output Classifier predicting statutory test sets (T1–T15).
⚖️ 2026 GSR 568(E) Substitution Optimizer
Implements Indian Legal Metrology Fourth Amendment Rules 2026: evaluates repeatability dispersion r = Emax - Emin to dynamically calculate statutory standard weights (r ≤ 0.2e → 20%, r ≤ 0.3e → 33.3%, or 50% Max).
